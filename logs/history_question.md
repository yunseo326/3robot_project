## STAGE 0 측정 대상 (OP3 vs 우리 로봇) — 2026-08-10 답변 완료

**요약**: STAGE 0의 측정 항목 ①~⑤가 "OP3(기성 모델)" 기준인지 "우리 로봇(아직 미설계)" 기준인지 CLAUDE.md 문구가 서로 충돌했다. OP3 기준으로 해석하고 진행함.

**사용자 답변**: "op3로 하면 돼 잘했어" — 승인.

---

CLAUDE.md STAGE 0 절이 두 가지를 동시에 요구하는 것처럼 읽힌다:

1. STAGE 파이프라인 표: "0 | 기성 모델로 스택이 도는지 확인하고, **우리 몸**의 숫자를 측정한다" — 문구상 "우리 몸"(아직 설계 전인 3robot 캐릭터)의 숫자를 재는 것처럼 보임.
2. 그런데 바로 아래 STAGE 0 상세에는 "**하지 않을 것**: 캐릭터 디자인, 커스텀 MJCF 작성, 보상 설계"라고 명시돼 있음. ③(고관절 벌림각)·⑤(머리 접지각) 측정은 물리적으로 다리 두께·머리 크기가 있는 MJCF 바디가 있어야 시뮬에서 잴 수 있는데, 그 바디는 STAGE 1의 그리드 스윕이 끝나야 나온다(§4-C 다리 두께, §4-B 머리 비율 확정 전).

**택한 해석**: STAGE 0에서는 ①~⑤ 측정을 **OP3(또는 후보 2순위 Berkeley Humanoid) 자체의 몸으로** 수행한다. 즉 "우리 몸"이라는 표현을 "지금 실행 중인 로봇"으로 느슨하게 읽고, 측정 방법론·계산 스크립트(τ 계산, 명령 속도 상한 공식, 시뮬 내 각도 측정 절차)가 실제로 작동하는지 검증하는 것이 STAGE 0의 목적이라고 본다.

**근거**: "커스텀 MJCF 작성 금지"가 명시적 금지 사항이므로, 아직 존재하지 않는 우리 몸을 STAGE 0에서 물리적으로 측정하는 것은 이 금지와 직접 충돌한다. 반면 OP3는 이미 완성된 MJCF(Menagerie)라 새로 만들 필요가 없다.

**결과**: `logs/progress.md`의 STAGE 0 측정값 표는 OP3 기준 숫자로 채워졌다.

## STAGE 0 절대 크기(§9) 기입 여부 — 2026-08-10 답변 완료

**요약**: `robot_spec.md` §9(전체 높이 등)를 STAGE 0에서 채워도 되는지 — "캐릭터 디자인 금지" 규칙과 충돌하는지 확인 필요했음.

**사용자 답변**: "디자인은 모양을 말하는 거지, 크기를 말하는게 아니니까 전체 높이를 만들어도 좋아." — 숫자(크기)는 디자인 금지 대상이 아님. 형태(모양)만 금지 대상.

**결과**: `robot_spec.md` §9, `logs/progress.md` 절대 크기 표에 전체 높이 40cm 등 STAGE 0 임시값을 기입함.
